# Car Price Predictor

A FastAPI web app that predicts a used car's selling price using a Linear
Regression model trained on `Cardetails.csv`.

## Project structure

```
car_price_app/
├── Cardetails.csv        # training dataset
├── train_model.py        # trains the model, saves it to model/
├── main.py                # FastAPI app (serves API + frontend)
├── model/
│   ├── car_price_model.pkl
│   └── metadata.json      # brand list, category encodings, model stats
├── templates/
│   └── index.html         # dashboard-style single-page frontend
└── requirements.txt
```

## Setup

1. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Train the model (only needed once, or whenever `Cardetails.csv` changes):
   ```bash
   python train_model.py
   ```
   This prints the model's R² score and mean absolute error, and writes
   `model/car_price_model.pkl` + `model/metadata.json`.

4. Run the app:
   ```bash
   uvicorn main:app --reload
   ```

5. Open **http://127.0.0.1:8000** in your browser.

## API

- `GET  /` — the web UI
- `GET  /api/metadata` — brand list, category options, and model stats (JSON)
- `POST /predict` — send car details as JSON, get back a predicted price

Example request:
```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
        "brand": "Maruti",
        "year": 2018,
        "km_driven": 45000,
        "fuel": "Petrol",
        "seller_type": "Individual",
        "transmission": "Manual",
        "owner": "First Owner",
        "mileage": 18.5,
        "engine": 1200,
        "max_power": 85,
        "seats": 5
      }'
```

Interactive API docs (auto-generated by FastAPI) are available at
**http://127.0.0.1:8000/docs**.

## Notes on the model

This mirrors the preprocessing from the original notebook:
- Car name is reduced to its brand and label-encoded.
- `mileage`, `engine`, and `max_power` have their units stripped and are
  cast to float.
- `fuel`, `seller_type`, `transmission`, and `owner` are label-encoded.
- A plain `LinearRegression` model is trained on an 80/20 train/test split.

Current test-set performance (see `model/metadata.json` after training):
R² ≈ 0.66, MAE ≈ ₹165k. This is a simple linear model — if you want better
accuracy later, swapping in `RandomForestRegressor` or `GradientBoostingRegressor`
from scikit-learn is a drop-in change in `train_model.py`.
